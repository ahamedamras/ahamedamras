## Contribution Snake

<div align="center">

The personalized snake animation requires a successful generation workflow before its SVG can be embedded.

[Open profile repository workflows](https://github.com/ahamedamras/ahamedamras/actions)

</div>

<details>
<summary><strong>Enable the purple contribution snake</strong></summary>

<br />

Save the following as `.github/workflows/snake.yml` in `ahamedamras/ahamedamras`, then run **Generate Contribution Snake** from the Actions tab.

```yaml
name: Generate Contribution Snake

on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:

permissions:
  contents: write

concurrency:
  group: contribution-snake
  cancel-in-progress: false

jobs:
  generate:
    runs-on: ubuntu-latest
    timeout-minutes: 10

    steps:
      - name: Generate purple contribution snake
        uses: Platane/snk/svg-only@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-contribution-grid-snake.svg?color_snake=#C4B5FD&color_dots=#161B22,#312E81,#5B21B6,#7C3AED,#A78BFA
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}

      - name: Publish SVG to output branch
        uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

After the workflow succeeds, replace this section's setup text with:

```html

</div>
```
